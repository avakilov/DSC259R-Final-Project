Power Outages Analysis

We analyze major power outages and predict an outage severity score built from OUTAGE.DURATION, DEMAND.LOSS.MW, and CUSTOMERS.AFFECTED. This is a regression problem with severity as a continuous target.

Project Goals

  • Understand relationships among outage duration, customers affected, and demand loss.
  • Define a meaningful, continuous measure of outage severity.
  • Train models to predict severity from available covariates (economic/demographic/climate).
  • Use EDA to motivate hypothesis tests (e.g., severe weather vs other causes).

Data & Features

We use climate, cause, time, and economic/demographic indicators to predict severity. The severity score is constructed from three core outage-impact variables and log-transformed to address heavy skew.

Key Severity Components

  • OUTAGE.DURATION (minutes/hours depending on dataset definition)
  • DEMAND.LOSS.MW
  • CUSTOMERS.AFFECTED

Example Predictors

  • CAUSE.CATEGORY, CLIMATE.CATEGORY, ANOMALY.LEVEL
  • RES/COM/IND/TOTAL PRICE and SALES features
  • Population density features (POPDEN_UC, POPDEN_RURAL, etc.)
